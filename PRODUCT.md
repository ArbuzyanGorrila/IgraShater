# CraftMine
<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop game, Unity 2022.3.62f3, C#.

## Users and purpose
Single-player grid puzzle for the supplied university project. The player digs a connected route through a mine, gathers every heart and avoids boulders.

## Confirmed capabilities
Ten authored rooms; WASD moves and faces, E mines forward; automatic character rewards for mining XP; ore gates require level and pickaxe; crafting between rooms; protection charges; three undos; progress is banked on victory. Replaying a completed room can earn resources again.

## Constraints
Use new sourced assets, never the pre-existing asset packs. Save changes in Git. Russian UI. Keep deterministic grid simulation separate from presentation. Windows keyboard and mouse.
